Party regression checks

Deterministic source-level browser checks for the independent character team. No account, external service, or package installation is required.

Open the repository root in VS Code and use the local HTTP server documented in README.md. With its default port, open http://127.0.0.1:8000/tests/party.html. Do not open this file using file://.

The companion test module is delivered separately. A missing module, import failure, or empty suite is a failure—not a passing result. Passing checks do not establish visual quality, real-device controls, audio playback, or full-level navigation performance.
